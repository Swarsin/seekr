# Demo Course Sources and License

All lecture notes, handouts, PDF documents, Word worksheets, PowerPoint slide
decks, Jupyter notebooks, and evaluation queries in this directory are original
educational materials written specifically for the `seekr` repository
(`seekr-search`).

No external textbooks, lecture slides, or copyrighted course packs were copied
or adapted. Every file in `machine-learning/`, `data-structures/`, and
`4CCS1LGC-logic/` is released under the project's MIT license (see the
repository `LICENSE` file).

The three PDF handouts are generated deterministically from their companion
Markdown files using `scripts/make_demo_files.py` and PyMuPDF. The demo Word
worksheet (`4CCS1LGC-logic/week2/natural-deduction-worksheet.docx`), PowerPoint
deck (`data-structures/week3/shortest-paths-dijkstra-slides.pptx`), and Jupyter
notebook (`machine-learning/week3/cross-validation-lab.ipynb`) are likewise
generated by `scripts/make_demo_files.py` using `python-docx`, `python-pptx`,
and stdlib `json`.
